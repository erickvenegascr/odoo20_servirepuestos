# Trabajo en este repositorio

La base canónica es el `main` remoto. Crear las nuevas ramas de trabajo desde `origin/main` actualizado y dirigir los PR a `main`, salvo una instrucción explícita del usuario.

Comprobar por separado qué rama está desplegada. Una actualización de `main` no demuestra que el entorno activo haya cambiado de versión. Conservar los cambios locales de otras tareas.
