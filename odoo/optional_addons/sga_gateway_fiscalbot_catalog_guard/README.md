# Protección de CABYS del catálogo SGA

Puente opcional que se instala con el módulo comercial SGA y FiscalBot.
Evita que una línea XML de proveedor copie su CABYS y descripción al maestro de
un producto procedente de SGA. Conserva el CABYS de la factura en su línea y el
comportamiento previo para productos locales. El gateway sigue conciliando el
catálogo SGA. No reescribe facturas ni cambia su vinculación de productos.
